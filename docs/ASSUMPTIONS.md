# Допущения MVP (явно)

1. **Данные:** все порты, рейсы, история и погода — синтетические (`data_quality=synthetic_demo`).
2. **Расписания:** `ScheduledService` — демо-слоты для стыковок, **не** официальное расписание линий.
3. **Документы:** статусы `accepted_for_review` / `incomplete` и т.п. — тестовые; **не** таможенное разрешение.
4. **Часовые пояса:** события в UTC; UI показывает Europe/Moscow и Asia/Tehran для портов РФ/Иран.
5. **CO₂e:** `ef_kg_per_tkm`: rail 0.028, sea 0.016, road 0.095 (условные демонстрационные коэффициенты).
6. **Стоимость альтернатив:** демо-тарифы USD, не оферта.
7. **Cutoff стыковки:** груз должен быть ready за 6 ч до demo-departure морского рейса.
8. **Без Docker:** локальный режим SQLite (`DATABASE_URL=sqlite+aiosqlite:///./sct.db`).
9. **Auth:** один тестовый API-key `demo-key`.
10. **CatBoost:** обучается только на synthetic history с time-split; при малом объёме UI использует median baseline.
11. **Figma:** файл «Диспетчерская» — целевой визуал; без edit-доступа UI собран как operational theme для сверки позже.
12. **Экономия / ROI:** не заявляется в MVP.
