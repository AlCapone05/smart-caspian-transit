Smart Caspian Transit — смысл проекта и как он работает
========================================================

ЧТО ЭТО
-------
Демо-диспетчерская для логиста на каспийском звене коридора «Север — Юг».

Мультимодальная перевозка (ж/д → порт → море → порт → авто) легко срывается:
погода, очередь в порту, пропуск морского рейса, дыры в документах.
Логист обычно сверяет это вручную часами.

Проект показывает, как система может заранее сказать: «рейс не успеете»,
пересчитать ETA, сравнить другие маршруты и проверить пакет документов —
в одном окне.

ВАЖНО: все данные синтетические (демо).
Статусы документов НЕ являются таможенным разрешением.


ДЛЯ КОГО
--------
Логист / диспетчер мультимодального оператора.


ЦЕННОСТЬ (для защиты)
---------------------
Логист за минуты видит сорванную стыковку, новый ETA и выбирает план
по времени / деньгам / выбросам — вместо часов ручной сверки.


КАК ДОЛЖЕН РАБОТАТЬ (СКВОЗНОЙ СЦЕНАРИЙ)
--------------------------------------
1. Обзор / Перевозки
   Список грузов с риском, задержкой и ETA.
   Главный кейс: SCT-2048 (Астрахань → Энзели).

2. Карточка груза
   Путь по плечам, таймлайн, риск.
   Сценарии «Шторм / Перегрузка» → симулятор пересчитывает стыковку
   с расписанием и новый прогноз прибытия.

3. Сравнить альтернативы
   Текущий маршрут / через Махачкалу / через Актау (часто недоступен).
   Выбор обновляет ETA, стоимость, CO₂e и план на карточке.

4. Документы
   Комплект из 5 файлов: добавить PDF, исправить ТН ВЭД,
   отправить на тестовый pre-check.

5. Сравнение грузов
   Несколько перевозок рядом по времени / цене / CO₂e / документам.

6. Аналитика / Настройки
   KPI коридора и параметры диспетчерской.


ТЕХНИЧЕСКИ
----------
React UI ↔ FastAPI ↔ SQLite (локально) / Postgres (Docker).

Локальный запуск:
  UI:  http://127.0.0.1:5173
  API: http://127.0.0.1:8002
  Ключ: X-API-Key: demo-key

ЧТО ВХОДИТ В MVP
----------------
- Список перевозок: статус, риск, план/прогноз ETA, задержка
- Карточка груза: маршрут, таймлайн
- Прогноз задержки (медиана + опционально CatBoost на синтетике)
- Симулятор условий (шторм, очередь)
- 2–3 альтернативы маршрута
- Проверка комплекта документов + тестовый pre-check
- Приближённый CO₂e
- Сравнение нескольких грузов


ЧТО НЕ ВХОДИТ (ОТЛОЖЕНО)
------------------------
- Блокчейн, 3D-визуализация порта
- Реальные интеграции (РЖД, TOS, AIS, таможня, погода в проде)
- Вероятности / интервалы прогноза без калибровки
- Автовыбор «лучшего» плана без решения логиста
